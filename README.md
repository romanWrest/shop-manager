1. **Клонируйте репозиторий**:

   ```bash
   git clone https://github.com/romanWrest/shop-manager.git
   ```

   Перейдите в директорию проекта

   ```bash
   cd shop-manager
   ```

2. **Конфигурация**:
   Файл `.env` намеренно исключен из `.gitignore`

3. **Запуск**:

   ```bash
   docker-compose up -d
   ```

   При возникновении проблем с запуском, выключить/включить vpn, попробовать еще раз

4. **Доступ к API**:
   API доступен для тестирования по адресу: [тык](http://localhost:3000/api)

5. **Документация API**:
   Спецификация Swagger/OpenAPI находится в файле `docs/openapi.yaml`.

6. **Тестовые данные**:
   Все примеры тестовых данных уже представлены в документации Swagger в разделах `example Value`.
   Единственное, небходимо будет копировать длинные ID, для создания последующих сущностей.

7. **Администраторы**:
   Пользователь с ролью `ROOT` автоматически добавляется в базу данных при запуске приложения через seed. Это единственный пользователь с ролью `ROOT` в системе. Ручка на изменение пароля есть. Как для любого администратора в системе(по id), так и для сущности в текущей сессии(админ, магазин), но тогда токен аннулируется.

8. **Логирование**:
   Oтсутствует, знаю что должно быть, и на латинице. Если возникнет такая необходимость, тогда исправлюсь.
